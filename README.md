# Lemuel Dipasupil — portfolio

My personal site, laid out like a corkboard: projects pinned up as polaroids and hackathon badges, with photos, classes and contact info.

Live at **https://lem-d.github.io/**

## What's here

- `index.html` — the whole site (HTML, CSS and a small script, no build step)
- `assets/` — logos and photos

On desktop the board scales to fit the window with no scrolling. On phones it becomes a normal scrolling page.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```

## Deploy

Hosted with GitHub Pages from the `main` branch root.
