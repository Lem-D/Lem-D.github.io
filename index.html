UASTARR · Firmware · Aug 2026

STARR Power Distribution

UASTARR site ↗Repo ↗

Firmware developer for the power distribution board on UASTARR's Alberio rocket.

  • I2C driver in C for the MAX17320 fuel gauge on an STM32L4: charge, voltage, current, temperature and faults.
  • Timeouts, 3-attempt retries and typed error codes, so a stuck sensor never stalls the main loop.
  • CAN fragmentation layer that splits full status reports across 8-byte frames.
  • Command dispatcher that lets other avionics boards switch power rails remotely.

Tinder for food: a group swipes on nearby restaurants and the first place everybody likes wins. I was a full-stack developer.
